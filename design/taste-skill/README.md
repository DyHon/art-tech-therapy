# Vendored design discipline — taste-skill (soft + minimalist)

Vendored copies of two design-discipline guides from
[`leonxlnx/taste-skill`](https://github.com/leonxlnx/taste-skill) (MIT — see
`LICENSE.taste-skill`). They are adopted as a **UI design-review reference** for this
project, not as runtime code. Decision record:
`vault/Projects/art-tech-therapy/decisions/2026-06-07-taste-skill-deferred-m5.md`.

## Files
- `soft-skill.SKILL.md` — "high-end visual design": depth, premium motion, layered cards.
- `minimalist-skill.SKILL.md` — "minimalist UI": editorial restraint, banned generic defaults.
- `LICENSE.taste-skill` — upstream MIT license.

## How we apply them here
- **Low motion** — mental-health context: calming, never stimulating. Framer Motion entrances
  are gentle and respect `prefers-reduced-motion` (see the `/safety` BreathingGuide).
- **Soft/minimalist blend** — muted slate/indigo palette, generous whitespace, rounded cards,
  restrained type.
- Use the guides' checklists as a **review gate** for new UI — not a literal restyle mandate,
  and never at the expense of clarity on the `/safety` route.
